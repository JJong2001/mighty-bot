# Mighty Bot

Tabletop Simulator에서 마이티 AI를 사용할 수 있도록 연결하는 로컬 봇입니다. 비딩, 바닥 정리, 프렌드 선택과 카드 플레이를 판단합니다.

**Windows x64용이며 Java가 포함되어 있어 별도 설치가 필요 없습니다.** 봇 연결을 지원하는 마이티 맵은 별도로 준비해야 합니다.

## 다운로드

**[최신 실행기 다운로드](https://github.com/JJong2001/mighty-bot/releases/latest)**

Releases에서 `MightyBot-버전-AutoUpdate-Windows-x64.zip`을 받으세요.

## 실행과 테탑 연결

1. ZIP **전체**를 압축 해제합니다.
2. `MightyBot.exe`를 실행하고, 준비 완료 메시지가 나타나면 창을 열어 둡니다.
3. 같은 PC의 Tabletop Simulator에서 마이티 맵을 열고 **연결 확인**을 누릅니다.
4. 맵에서 봇을 사용할 자리를 설정하고 게임을 진행합니다.

`MightyBot.exe`와 `app`, `runtime` 폴더는 함께 두세요. 봇을 종료하려면 실행 창을 닫으면 됩니다.

연결되지 않으면 준비 완료 메시지와 폴더 구성을 확인하고, 기존 봇을 종료한 뒤 다시 실행해 보세요.

## 자동 업데이트

실행할 때 최신 엔진을 확인하고 새 버전이 있으면 자동으로 받습니다. **업데이트하려면 봇을 종료한 뒤 다시 켜세요.** 업데이트에 실패하면 기존 버전으로 실행합니다.

일반적인 엔진 업데이트는 ZIP을 다시 받을 필요가 없습니다. 업데이트 주소가 없는 구형 실행기나 실행기 자체가 변경되는 경우에는 새 ZIP으로 교체해야 할 수 있습니다.

## 복기와 점수 기록

기록은 기본적으로 꺼져 있습니다. 기록을 지원하는 맵에서 배포 폴더의 `record_settings.cmd`로 복기·점수 기록을 켜거나 기록 폴더를 열 수 있습니다.

기록은 PC의 `%LOCALAPPDATA%\MightyBot\records`에 저장됩니다.

## 오류와 플레이 피드백

**[GitHub Issues에 제보하기](https://github.com/JJong2001/mighty-bot/issues)**

문제가 발생한 버전과 상황을 알려주세요. 잘못된 플레이라면 공약, 프렌드 지정, 구 번호, 자리 순서, 관련 손패와 이미 나온 카드를 함께 적어주면 원인을 확인하는 데 도움이 됩니다.
